# Differences from the unmodded game

Trainer Desk changes how the window is laid out. It does not change the game.

## Game data and rules

Nothing. No species, moves, items, maps, text, trainers, encounters or battle rules are added or changed.

## Screen

- The game picture is drawn in the middle of the window, smaller, to make room for docks on the left, right and bottom. With every dock hidden (F10 by default) the game has the whole window again.
- Panels registered by other mods are drawn in the docks or in their own desktop windows.
- A small menu button appears in the corner of the game area.

## Input

- Mouse clicks and the wheel over a dock go to the panel there instead of the game. Over the game picture the wheel is still the game's zoom.
- F10 (configurable) shows and hides the docks.
- Keyboard and gamepad input to the game is untouched.

## Saves

The save file is not read or written. The layout, the theme and which panels are closed or floating are kept in the mod's own cache.

## Turning it off

Disable the mod and the game window is exactly as before. Nothing is left in the save.
